- LESVOS_CULTURE_Report.pdf : τελικό report σε PDF

- AI_REPORT.txt : αναφορά χρήσης Τεχνητής Νοημοσύνης

ΜΟΝΟ ΕΝΑ ΒΗΜΑ ΜΕΝΕΙ ΑΠΟ ΤΗ ΦΟΙΤΗΤΡΙΑ:
1. Ανεβάστε τον φάκελο site σε δωρεάν web hosting (π.χ. GitHub Pages).
2. Αντιγράψτε το δημόσιο URL στο πεδίο URL του report.
3. Ανοίξτε το URL από κινητό και υπολογιστή και κάντε έναν τελικό έλεγχο των εξωτερικών embeds.
4. Υποβάλετε το ZIP στο eClass.
